# Clipboard Text to TXT File Input (Chrome Extension)

Расширение вставляет текст из буфера обмена в активное поле загрузки файла (`<input type="file">`) как `.txt` файл по горячей клавише.

## Как это работает

1. Скопируйте нужный текст в буфер обмена.
2. Кликните в поле загрузки файла на сайте (чтобы оно стало активным).
3. Нажмите горячую клавишу:
   - **Windows/Linux:** `Ctrl+Shift+Y`
   - **macOS:** `Cmd+Shift+Y`
4. В поле будет подставлен виртуальный файл вида `clipboard-<timestamp>.txt`.

## Установка (режим разработчика)

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку проекта (`/workspace/TxtCopy`).

## Изменение горячей клавиши

1. Откройте `chrome://extensions/shortcuts`.
2. Найдите расширение **Selected Text to TXT**.
3. Поменяйте команду **Вставить текст из буфера как TXT-файл** на нужную комбинацию.

## Ограничения

- Если активно не поле `input[type=file]`, вставка не сработает.
- Если буфер обмена пуст, файл не будет создан.
- Некоторые сайты могут ограничивать программную подстановку файла своей логикой.
