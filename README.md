# Selected Text to TXT (Chrome Extension)

Расширение сохраняет выделенный на странице текст в `.txt` файл по горячей клавише.

## Что делает

1. Вы выделяете текст на любой веб-странице.
2. Нажимаете горячую клавишу:
   - **Windows/Linux:** `Ctrl+Shift+Y`
   - **macOS:** `Cmd+Shift+Y`
3. Браузер предлагает сохранить TXT-файл с выделенным текстом.

## Установка (режим разработчика)

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку проекта (`/workspace/TxtCopy`).

## Изменение горячей клавиши

1. Откройте `chrome://extensions/shortcuts`.
2. Найдите расширение **Selected Text to TXT**.
3. Поменяйте команду **Сохранить выделенный текст как TXT** на нужную комбинацию.

## Примечания

- Если текст не выделен, файл не создаётся.
- Расширение использует разрешения `activeTab`, `scripting`, `downloads`.
